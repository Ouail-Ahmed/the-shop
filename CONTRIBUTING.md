# Contributing guide

Thank you for contributing to The Shop.

## Development workflow

1. Fork or branch from `main`.
2. Name your branch descriptively (for example, `feat/product-card` or `fix/cart-count`).
3. Make focused, minimal changes.
4. Verify that linting and builds succeed:
   ```bash
   npm run lint
   npm run build
   ```
5. Open a pull request against the `main` branch.

## Pull request guidelines

- Fill out the provided pull request template completely.
- Keep pull requests small and focused on a single concern.
- Ensure the project builds cleanly without errors or warnings.
